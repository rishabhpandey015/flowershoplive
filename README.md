# 🌸 FlowerShop.com

This is a simple static front-end design for a flower shop website using only HTML. It includes:

- A branded header with social media icons and logo
- Navigation menu (Home, Shop Online, Contact Us, About Us)
- Search bar for flower search
- Shop online form with input fields (Name, Flower Name, Quantity, Mobile No, Address)
- A promotional image section
- Footer with contact and developer credits
